Guida Setup Firebase

Segui questi passaggi una volta sola per attivare la sincronizzazione realtime:

  1. Vai su console.firebase.google.com e accedi con il tuo account Google
  2. Clicca "Crea un progetto" → dai un nome (es. "chronicler-gdr") → continua fino alla fine
  3. Nella sidebar del progetto: "Build → Authentication" → attiva il provider "Google"
  4. Vai su "Build → Firestore Database" → crea il database → scegli la regione più vicina → modalità produzione (le regole le impostiamo dopo)
  5. In Firestore → Regole, incolla queste regole e pubblica:
    rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { match /shared/{doc=**} { allow read, write: if request.auth != null; } match /private/{uid}/{col}/{doc=**} { allow read, write: if request.auth.uid == uid; } } }
  6. Vai su "Storage" → attiva (stesse regole: autenticati possono leggere/scrivere)
  7. Vai su "Impostazioni progetto" (⚙) → scorri fino a "Le tue app" → clicca "</> Web" → registra l'app
  8. Copia i valori apiKey, authDomain, projectId, storageBucket, messagingSenderId, appId e incollali nel file index.html nella sezione FIREBASE CONFIG
  9. Su GitHub: crea un repo pubblico, carica il file index.html, attiva Pages (Settings → Pages → Branch: main)
  10. Aggiungi l'URL di GitHub Pages nelle "Authorized domains" di Firebase Auth
